Why "Official", "Pure" and "Plus" Mean Little

Anyone can put "official", "pure" or "plus" on a download page. None of those words tells you who publishes the app, which package you will get, or whether it is the same app your friend installed. The package name and the publisher do.

How to Check Which Yono Arcade You Have

  • Package name: Settings → Apps → the app → App details. Compare it with the table above.
  • Publisher: a Play listing names one; a download website usually does not.
  • File name: a file named after a different brand is a warning sign.
  • Permissions: see our APK safety notes.
